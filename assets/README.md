## 📝 About Build //localhost

Use this short description in your event pages, emails, or promotions:

Microsoft Build //localhost is a global series of community-led, hands-on, in-person learning events designed to extend Microsoft Build content into local technical communities.

Hosted between June 4–26, 2026, each event includes demos, hands-on labs, and opportunities to connect with fellow developers.
